Android

Get the app

Download app (APK, 4 MB)
  1. Tap Download app, then open the downloaded file.
  2. If the phone asks, allow Install unknown apps for Chrome, then tap Install.
  3. Open the app and allow Location.

ڈاؤن لوڈ کریں، فائل کھولیں اور Install دبائیں۔ اگر فون پوچھے تو Install unknown apps کی اجازت دیں۔ ایپ کھول کر لوکیشن کی اجازت دیں۔
